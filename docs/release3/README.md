# Twitter Clone Release 3

## Implemented in Release 3

- **Like functionality** for posts
- **Retweet functionality** for posts
- **Delete functionality** for posts
- **REST API** as the server implementation
- **API client** that consumes the REST API
- **UI improvements** across all FXML views
- **Profile page** - Allows the user to log out, view their own posts, and see personal stats
- **Tests** - New and improved tests to increase test coverage across the application (including both unit tests and JavaFX integration tests)
