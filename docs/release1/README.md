# Twitter Clone Release 1



## Features implemented in Release 1

* **Post data class** – represents tweets (content, author, timestamp, etc.)
* **User data class** – represents registered users (username, display name, etc.)
* **Persistence layer** – save and load posts and users from disk (JSON-based storage)
* **Unit tests** for persistence layer
* **UI: New Post** – create and submit new posts
* **UI: Login** – basic login screen for existing users
* **UI: Feed** – display a timeline of posts
